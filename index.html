미리보기

간단한 도움말

  • MD 열기: 기존 Markdown 파일을 불러옵니다.
  • 편집: 큰 화면에서는 좌우로 표시됩니다. 휴대폰에서는 소스 편집과 미리보기 버튼으로 전환하세요.
  • MD 저장: 편집본을 다운로드합니다. 단축키는 Ctrl+S 또는 ⌘+S입니다.
  • HTML 내보내기: 미리보기를 HTML 파일로 다운로드합니다.
  • PDF로 저장: 인쇄 창에서 ‘PDF로 저장’을 선택하세요. 인쇄 창이 열리지 않으면 HTML로 내보낸 파일을 브라우저에서 열고 브라우저의 인쇄 기능을 사용하세요.

홈 화면 설치: 앱 설치 버튼 또는 Chrome 메뉴의 ‘홈 화면에 추가’를 사용하세요. 처음에는 HTTPS 주소에서 열어야 합니다.

문법 예시: # 제목, **굵게**, - 목록
