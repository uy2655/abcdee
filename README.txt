Markdown 편집기 PWA

1. ZIP을 풀어 index.html, manifest.json, sw.js, PNG 아이콘 2개를 같은 폴더에 유지하세요.
2. 그 폴더를 HTTPS 정적 호스팅에 올리세요. file://로 index.html을 직접 열면 편집 기능만 쓸 수 있고 앱 설치와 오프라인 캐시는 동작하지 않습니다.
3. Android Chrome에서 배포 주소를 온라인으로 한 번 여세요. 상단 ‘앱 설치’ 또는 Chrome 메뉴 ‘홈 화면에 추가’ → ‘설치’를 사용하세요. 메뉴 이름은 Chrome 버전에 따라 다를 수 있습니다.
4. 설치 후 네트워크를 끄고 홈 화면 아이콘에서 다시 실행해 오프라인 동작을 확인하세요.

작은 화면은 편집/미리보기 탭, 넓은 화면은 좌우 분할입니다. 문서는 자동 저장되지 않으므로 MD 저장을 사용하세요. PDF는 브라우저의 인쇄 기능을 사용하며, 설치 모드에서 인쇄가 되지 않으면 HTML로 내보낸 뒤 Chrome에서 열어 인쇄하세요.
배포 파일을 업데이트할 때는 sw.js의 캐시 버전도 변경하세요.
